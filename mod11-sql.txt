Module 11 Lab: Deploying SQL Server on Linux 🐧
Background 📚
SQL Pizza
This lab will guide you through deploying Microsoft SQL Server on Linux. We'll be setting up SQL Server in a GitHub Codespace using Docker. Using Docker containers provides isolation, easy cleanup, and consistent behavior across different environments.

After setting up your SQL Server together in class, you'll practice creating a database for a pizza delivery system. 🍕 Let's get started!


Pre-Requisites ✅
You need a GitHub account. If you haven't set this up yet, please complete Module 3 Lab before starting this Lab.

Part 1: In-Class Activity

Step 2: Pull and Run SQL Server 🐳
Open the Terminal.
Copy and paste this command as one line, and press enter to run it.
This command will take a few minutes to run, as it is downloading SQL Server from Microsoft's server and installing SQL Server in your virtual environment. You'll be prompted to open this on port 1433, but ignore this message. This is a database server, not a web server, so there's nothing to display in the browser.
docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=YourStrongP@ssw0rd" -e "MSSQL_PID=Developer" -p 1433:1433 --name sqlserver --health-cmd '/opt/mssql-tools/bin/sqlcmd -S localhost -U sa -P "YourStrongP@ssw0rd" -Q "SELECT 1" || exit 1' --health-interval 10s --health-timeout 3s --health-retries 10 --health-start-period 10s -d mcr.microsoft.com/mssql/server:2022-latest
Let's understand this command:

Creates and starts a new container for SQL Server.
Sets up necessary passwords and configurations..
Maps port 1433 for database connections
Includes health checks to ensure SQL Server is running properly.

Step 3: Install SQL Server Command-Line Tools 🛠️
Run each command one-by-one. 
# Add Microsoft repository to your environment
curl https://packages.microsoft.com/config/ubuntu/20.04/prod.list | sudo tee /etc/apt/sources.list.d/msprod.list

# Import GPG key
# GPG (GNU Privacy Guard) is an encryption software that helps
# secure digital communications. Microsoft, like many software
# vendors, signs their Linux packages with a GPG key. 
curl https://packages.microsoft.com/keys/microsoft.asc | sudo apt-key add -

# Update the package list
sudo apt-get update

# Install Microsoft SQL tools 
# (These tools allow you to run SQL statements on your
# SQL Server.)
sudo ACCEPT_EULA=Y apt-get install -y mssql-tools unixodbc-dev

# Add the SQL tools to the PATH variable 
echo 'export PATH="$PATH:/opt/mssql-tools/bin"' >> ~/.bashrc
source ~/.bashrc

Step 4: Verify Installation 🔍
# Test the connection
/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrongP@ssw0rd' -Q "SELECT @@VERSION"

Step 5: Create a Test Database 📦
# Create a new database
/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrongP@ssw0rd' -Q "CREATE DATABASE TestDB"

# Verify the database was created
/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrongP@ssw0rd' -Q "SELECT name FROM sys.databases"

Step 6: Managing Your SQL Server Container 🎮
# Stop SQL Server
docker stop sqlserver

# Start SQL Server
docker start sqlserver

# View container logs
docker logs sqlserver

# Check container status
docker ps -a

Step 7: Clean Up 🧹
When you're finished with the lab, shutdown the Docker container:

# Stop the container
docker stop sqlserver

# Verify SQL Server is running

Build Your Pizza Delivery Tracking System 🍕
Let's create a database to track campus pizza deliveries! First, connect to TestDB:

/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrongP@ssw0rd' -Q "USE TestDB"
Now let's create tables for our pizza delivery system:

/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrongP@ssw0rd' -Q " CREATE TABLE Drivers ( DriverID INT PRIMARY KEY IDENTITY(1,1), Name VARCHAR(50) NOT NULL, VehicleType VARCHAR(20), Rating DECIMAL(3,2) ); CREATE TABLE Orders ( OrderID INT PRIMARY KEY IDENTITY(1,1), CustomerName VARCHAR(50) NOT NULL, PizzaType VARCHAR(30) NOT NULL, OrderTime DATETIME DEFAULT GETDATE(), DeliveryTime DATETIME, DriverID INT FOREIGN KEY REFERENCES Drivers(DriverID), TotalAmount DECIMAL(10,2), Rating INT CHECK (Rating BETWEEN 1 AND 5) )"
Let's add our campus delivery drivers:

/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrongP@ssw0rd' -Q " INSERT INTO Drivers (Name, VehicleType, Rating) VALUES ('Alex', 'Electric Scooter', 4.8), ('Abdi', 'Hybrid Car', 4.9), ('Bao', 'Bicycle', 4.7), ('Mariyama', 'Motorcycle', 4.6)"
Add some sample pizza orders:

/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrongP@ssw0rd' -Q " INSERT INTO Orders (CustomerName, PizzaType, OrderTime, DeliveryTime, DriverID, TotalAmount, Rating) VALUES ('Chris', 'BBQ Chicken', '2024-01-12 18:00:00', '2024-01-12 18:30:00', 1, 18.99, 5), ('Pat', 'Pepperoni Supreme', '2024-01-12 18:15:00', '2024-01-12 18:50:00', 2, 20.99, 4), ('Taylor', 'Veggie Delight', '2024-01-12 18:30:00', '2024-01-12 19:00:00', 3, 17.99, 5), ('Jamie', 'Buffalo Ranch', '2024-01-12 18:45:00', '2024-01-12 19:15:00', 4, 21.99, 4)"

Try These Fun Queries! 🚀
1. Find the speediest delivery drivers:

/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrongP@ssw0rd' -Q " SELECT d.Name, d.VehicleType, AVG(DATEDIFF(MINUTE, o.OrderTime, o.DeliveryTime)) as AvgDeliveryMinutes FROM Drivers d JOIN Orders o ON d.DriverID = o.DriverID GROUP BY d.Name, d.VehicleType ORDER BY AvgDeliveryMinutes ASC"
2. Discover the campus favorites:

/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrongP@ssw0rd' -Q " SELECT PizzaType, COUNT(*) as OrderCount, AVG(Rating) as AvgRating FROM Orders GROUP BY PizzaType ORDER BY OrderCount DESC"
3. Calculate our delivery champions:

/opt/mssql-tools/bin/sqlcmd -S localhost -U SA -P 'YourStrongP@ssw0rd' -Q " SELECT d.Name, d.VehicleType, COUNT(o.OrderID) as Deliveries, AVG(o.Rating) as AvgRating, SUM(o.TotalAmount) as TotalSales FROM Drivers d LEFT JOIN Orders o ON d.DriverID = o.DriverID GROUP BY d.Name, d.VehicleType ORDER BY AvgRating DESC"

Troubleshooting 🔧
If you run into issues:

Check if SQL Server is running:
docker ps
View SQL Server logs:
docker logs sqlserver # This shows you detailed logs to help identify any issues
If you need to reset everything and start fresh:
docker rm -f sqlserver # Then run the original docker run command from Step 2
